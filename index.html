计算机基础知识

01计算机基础知识

PB TB GB MB KB B ：相邻进制为1024
1B=8b
电脑：KB=2^10 MB=2^20 GB=2^30 TB=2^40 PB=2^50
常用换算：KB=10^3 MB=10^6 GB=10^9

Internet四层结构：网络接口层、网络层、传输层、应用层

CD-ROM:只读型光盘

电脑-微型计算机

JAVA、phton：计算机语言

鼠标、手写板：输入设备

绘图仪：类似打印机

20多人的小型网络办公环境：局域网

微处理器：运算器和控制器

IOS、windows：系统

计算机病毒没有自愈性

CPU：中央处理器

HDMI：High-Definition Multimedia Interface 高清音视频接口

量子计算机：解决能耗问题
晶体管原理（芯片）与量子力学有关

计算机数据存储容量基本单位：字节

按信号的性质份，总线分为：数据总线、地址总线、控制总线

web浏览器收藏夹收常的是：网页地址

先于或者随着操作系统装入的病毒：引导区型病毒

宽带：把外网拉到自己家的服务
路由器：把宽带分给多台设备的硬件设备

以路由器为中心所有设备都连它叫星型拓扑

终端：用文字命令控制电脑的黑窗口

终端：只负责输入输出的设备（不自己运算）
主机： 能独立运算、有 CPU / 系统的计算机
节点： 网络里的一个 “连接点”

分时操作系统：多个终端使用一台计算机

MIPS：Million Instructions Per Second
中文：百万条指令每秒
描述：CPU性能

1946年世界上公认的第一台电子计算机是ENIAC（埃尼阿克）

存储速度追快的是：缓存（Cache）> 内存 (RAM) > 硬盘 > 光盘、U 盘

操作系统：用户与计算机之间的接口
让硬件听话、让软件能跑、让人能用的那个核心系统
操作系统是系统软件，不是硬件

CPU与数据总线位数相同：CPU一次能处理多少位数据，数据总线就必须传多少位，这样才不浪费、不卡顿。

计算机安全设置：停掉guest密码，强密码，强制权限等

计算机安全：不收自然、人为危害

输出设备：打印机、绘图仪、显示器

冯、诺依曼 贡献：二进制、存储程序

国标码：国家定的标准（国标码的编码范围容易和ASCII码冲突）
内码：电脑用的实际存储
内码 =国标码+偏移值8080H（H表示16进制的意思）

字长–CPU性能指标：CPU一次能处理的二进制数据位数
CPU主要性能指标：字长、主频、运算速度

计算机五大部件：运算器、控制器、存储器、输入设备、输出设备
控制器 = 指挥官，管顺序、发指令、协调所有部件。

描述计算机执行速度的单位Hz

计算机网络是一个在协议控制下的多机互联系统

ROM：只读存储器，不能随意修改（淘汰）（ONLY）

IP地址用来唯一标识网络中的主机，实现主机之间的通信与数据传输。可以通过ip查到连接设备的大概地理位置，以及运营商，如移动、联通。
IP地址（IPv4）所有连网设备的地址的标准格式。
点分十进制格式：XXX.XXX.XXX.XXX
由4段十进制数字组成、段与段之间用小数点.隔开、每一段范围：0255
合法例子：192.168.1.1 8.8.8.8 255.255.255.0
非法例子：
192.168.1（只有3段）
192.168.1.256（256超出0255）
192.168.01.1（不能有前导 0，考试常考）

微型计算机中控制器功能：控制机器各个部件协调工作。

ISDN：综合业务数字网 = 一条线同时上网+打电话。
以前的网络：电话网：只传声音、电报网：只传文字、数据网：只传电脑数据（上网）

计算机软件包括：程序、数据、相关文档
程序（怎么做）：就是代码、指令
数据（处理的内容）：文字、图片、账号、配置、表格……
相关文档（说明怎么用）：使用说明书、设计文档、维护手册、帮助文件

计算机软件 = 系统软件 + 应用软件
系统软件（管电脑的）
操作系统：Windows、Linux、Android、iOS+驱动程序+编译软件、数据库等
应用软件（给人用的）
QQ、微信、浏览器、Office、游戏、播放器……

系统软件核心：操作系统

源程序：程序员用高级语言写出来的、还没编译的原始代码程序，就叫源程序。

计算机网络的主要功能：数据通信、分布式信息处理、资源共享

拓扑结构 = 网络的连接形状和布局。
星型结构—— 中间一个集线器 / 交换机，大家连它
总线型结构—— 一根总线，大家都挂在上面
环型结构—— 连成一个圈
树型结构—— 像树一样，分层连接
网状结构—— 任意两点之间都能连

电脑/服务器真正认的是 IP 地址（如 180.101.49.11）
浏览器会通过DNS（域名系统）把域名翻译成 IP，再找到服务eg:
域名：www.baidu.com
多个ip:180.101.49.11、180.101.49.12（国内主流）等
三、域名的结构
以 www.baidu.com网址为例：
顶级域名：.com（商业）、.cn（中国）、.org、.net 等
二级域名：baidu（你自己注册的名字）
三级域名：www（常用前缀）

DOS（Disk Operating System）：磁盘操作系统，是纯文字黑底界面，只能用键盘敲命令，没有鼠标

计算机低级语言：机器语言和汇编语言

计算机网络最突出优点：资源共享和快速通信

02数据结构与算法

循环队列有对头和队尾指针共同决定

支持子程序（函数）调用的数据结构是栈

5个度为2的节点，该二叉树的叶子结点个数为6
N0=N2+1;

完全二叉树N1=0/1；

算法有穷性：运行时间有限

排序算法 最坏时间复杂度 空间复杂度 稳定性
冒泡排序 O(n2) O(1) 稳定
插入排序 O(n2) O(1) 稳定
选择排序 O(n2) O(1) 不稳定
快速排序 O(n2) O(logn) 不稳定
希尔排序 O(n2) O(1) 不稳定
二分查找 O(logn) O(logn) 不稳定
归并排序 O(nlogn) O(n) 稳定
堆排序 O(nlogn) O(1) 不稳定

快速排序需要排序的次数n*(n-1)/2

队列存储空间 Q(1:35)：表示队列有 35 个位置，下标从1到35；
front：队头指针，指向队头元素的前一个位置；rear：队尾指针，指向队尾元素的位置。
front=rear时：0/满
rear>front时：r-f
rear<front时:r+v-f

队列服务：先到先服务作业调度

若后序遍历和中序遍历序列相同，每个节点都没有右子树

对数据进行压缩会降低算法的空间复杂度

完全二叉树和满二叉树可以用顺序存储结构表示，其他用链式存储结构

二叉链表：存储二叉树的链表
数据域：存节点的值；
左指针域：指向左孩子节点；
右指针域：指向右孩子节点。

多重链表：指针域的个数不确定

顺序存储结构可以是非线性结构，如二叉树的顺序存储。

结构图的宽度看同一辈的（迷惑：同一辈的相连）

双向链表：具有两个指针域的线性结构

D=（1,2,3，4,5,6）,B=（D,R）
R=（6,1）（5,6）（1,3）（2,4）（3,2）

03程序设计基础

程序流程图中，有箭头的线段：控制流
数据流程图中，有箭头的线段：数据流

面向对象编程的三大特性：封装、继承、多态

程序调试任务：诊断和改正程序中的错误

对象是属性和方法的封装体；对象间的通信靠消息传递。

对象标识具有唯一性。

结构化程序的三种基本结构：顺序、循环、选择

程序化设计风格：程序结构良好、程序易读性高、不滥用goto语句

DFD：需求分析（只画数据流，不写算法）
例如：【学生】──(成绩)──→【录入成绩】──(成绩)──→【成绩表】
需求分析阶段产生的主要文档是：软件需求规格书

程序流程图、N-S、PAD等：软件设计（画程序逻辑/算法/伪代码）
例如：
开始
↓
sum=0, i=1
↓
输入 n
↓
while i ≤ n
sum = sum+i
i = i+1
↓
输出 sum
↓
结束

软件生命周期：软件产品从提出、实现、使用、维护、停止使用退役的过程

耦合性和内聚性是对 模块独立性 度量的两个标准：遵循 高内聚低耦合

软件危机表现是：软件开发生产率低、软件质量难以控制、软件开发成本高

黑盒测试–测功能：只关心「输入什么 → 输出什么」，完全不管内部代码怎么写。
白盒测试–测结构：完全打开盒子，盯着代码逻辑、路径、结构去测。
白盒测试方法：逻辑覆盖

软件需求规格说明书的作用：软件验收的依据、用户与开发人员对软件要做什么的共同理解、软件设计的依据（功能结果）
不对软件可行性，程序实现过程研究

软件工程的三要素：方法、工具、过程

逻辑模型：关系模型

软件测试用例包括：输入数据、预期输出结果

数据流图（DFD）突出表明了数据的源点和终点。
DFD构造规则是：
遵循自顶向下、逐层分解，先整体，再细节。
数据存储、加工必须既有流入，又有流出；
外部实体之间、数据存储之间不能直接连数据流；
数据流必须从加工出发或到加工结束；
每个成分必须命名（加工、数据流、存储、实体都要有名字）。

04数据库设计基础

数据管理技术发展三个阶段：人工管理阶段、文件系统阶段、数据库系统阶段

数据库应用系统核心：数据库设计

将E-R图转换为关系模型时，实体和联系都可表示为：关系（表）
将E-R图转换成关系数据模型的过程属于：逻辑设计阶段

关系：二维表 例：学生表、课程表
元组：行（记录） 例：一行就是一个学生的信息
属性：列（字段） 例：2024…10633
主键：唯一标识一行的那个字段（或组合） 例：学号、课程号
外键：关联其他表的列 例：学生表中的 “班级号”（关联班级表）
注：有时键即主键

E-R图：
符号形状 代表含义
🟦 矩形 实体
🟢 椭圆形 属性
🔷 菱形 联系
↔️ 连线 关联关系

关系的操作：
选择选行，投影选列；并是合集，交是共集。
R、S进行自然连接时，要求R和S含有共同属性。

数据库设计反应用户对数据要求的模式：外模式
对存储方式和物理结构的逻辑进行描述：内模式

一个老师可讲授多门课，一门课可以有多个老师讲授，则老师和课程之间的关系是：m:n

数据字典 = DFD数据流图的 “说明书 / 注释本”
数据字典（DD）所定义的对象都包含于：数据流程图DFD

数据库设计过程：概念设计、逻辑设计、物理设计（不包含算法设计）
关系模型设计属于逻辑设计；

关系数据库的规范化是为了解决：插入、删除异常和数据冗余的问题

按照传统的数据模型分类，数据库系统可分为：层次、网状、关系

第二范式在第一范式的基础上消除了：非主属性对主键的部分函数依赖
eg:姓名只依赖学号，课程名只依赖课程号👉 姓名、课程名 只依赖主键的一部分→踢出单独成表

数据库管理系统功能：数据库定义、数据库的建立与维护、数据库的访问

数据库特点：数据能共享且独立性高

实体之间多对多联系在关系模型中实现的方式是：建立新的关系

数据库三级模式体系结构的划分有利于保持数据库的数据独立性

数据库中存储的是：数据+数据之间的联系
