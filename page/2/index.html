串口调试助手模式组合对照表
接收：ASCII 接收数字解析显示为ASCLL码对应字符 eg:发送0x41 串口助手接收为’A’;
发送：ASCII 发送字符解析并发送为ASCLL码值 eg:串口助手发送’A’ 电脑接收到0x41
接收：Hex接收数字解析显示为ASCLL码值 eg:发送’A’ 串口助手接收为0x41;
发送：Hex发送数字解析并发送为对应ASCLL码对应的字符eg:串口助手发送41 电脑接收到’A’;

keil工程的基本框架

├─ myProject #你的工程名
│ ├─Application/MDK-ARM
│ └─ Application/User/Core
│ └─ Drivers/STM32G4xx_HAL_DriverApplication/User/Core
│ └─Drivers/CMSIS
│ └─user #自己建的
│ └─ bsp_system.h #存放各个.h文件、全局变量、
│ └─ system.c #存放系统初始化函数
│ └─ sheduler.c #任务调度器协调不同函数进程
│ └─ xxx_user.c #各个模块.c文件
